# 随身 WiFi 流量卡统计 (Home Assistant 自定义集成)

通过金迈物联（小末智能渠道）公开查询接口，在 Home Assistant 中展示随身 WiFi / 流量卡的用量与状态。

> 本集成仅做**只读查询**，不会充值、不会修改套餐、不会控制卡片。

## 功能

每 10 分钟自动刷新，提供以下传感器：

| 传感器 | 单位 | 说明 |
|---|---|---|
| 已用流量 | GB | 当前周期已使用 |
| 剩余流量 | GB | 总流量 − 已用 |
| 总流量 | GB | 套餐总量 |
| 账户余额 | 元 | 现金余额 |
| 赠送余额 | 元 | 赠送金额 |
| 卡片状态 | — | 正常 / 异常 |
| 到期时间 | — | 套餐到期日 |
| 更新时间 | — | 上游数据时间 |

支持 **Config Flow** 图形化配置，并内置 **Options Flow**：token 过期后可直接在
「设置 → 设备与服务 → 本集成 → 配置」里更新 token，无需删除后重新添加（实体与历史保留）。

## 安装

### 方式一：HACS（手动添加自定义仓库）

HACS → 集成 → 右上菜单 → 自定义存储库，填入本仓库地址，类别选「集成」，安装后重启 HA。

### 方式二：手动安装

把 `custom_components/liuliangka` 目录复制到 HA 配置目录下的 `custom_components/`：

```
<config>/custom_components/liuliangka/
```

然后重启 Home Assistant。

## 配置

1. 设置 → 设备与服务 → 添加集成 → 搜索「流量卡统计」。
2. 填写：
   - **ICCID**：你的流量卡 ICCID（卡面 / 购买渠道可查）。
   - **customId**：渠道号，小末智能渠道默认 `7505121`，其它渠道请按实际填写。
   - **token**：查询接口所需的访问令牌。
3. 提交即可。token 失效后用集成卡片上的「配置」更新，无需重建。

## 隐私说明

- 你的 ICCID / token 仅保存在本地 HA 的 `.storage/core.config_entries` 中，不会发送给除上游查询接口之外的任何第三方。
- 仓库代码不包含任何真实 ICCID、token 或个人信息。
